# 指标口径与工具误差

> 这一篇是前两篇的「使用说明」：每个指标怎么取数、误差多大、什么情况下不能下结论。

## 指标口径速查

| 指标 | 取数范围 | 工具 | 主要误差来源 |
|---|---|---|---|
| 核心词月搜索量 | 该词近 30 天搜索量 | 卖家精灵 关键词选品 | 搜索量是估算，非亚马逊官方披露 |
| 月增长率 | 同比 / 环比增速 | 卖家精灵 关键词选品 | 季节性未剔除时会被高估 |
| TOP100 月均销量 | 小类前 100 名 ASIN | 卖家精灵 选市场 | 由 BSR 反推，头部较准、尾部偏差大 |
| 类目月总容量 | 前 20 名预估月销量求和 | 卖家精灵 选市场 | 遗漏长尾，通常低估真实容量 |
| 品牌集中度 | 前 3 品牌销量 / 总销量 | 卖家精灵 选市场 | 同品牌多链接归属判定可能漏并 |
| Top20 平均评论数 | 前 20 名 ASIN 评论数 | 卖家精灵 / 前台 | 评论抓取有延迟，新品评论可能漏计 |
| 点击集中度 | 前三 ASIN 点击量 / 关键词总点击量 | 卖家精灵 关键词分析 | 仅覆盖该词搜索结果页，不含关联流量 |
| 新品数量 | 近 6/12 个月进入 BSR 前 100 | 卖家精灵 选市场 | 以上架时间判定，变体合并会失真 |

## 误差意识的三条纪律

1. **区间思维**：任何销量数字都要当区间看。头部 ASIN ±30%、腰部以下可能 ±50% 以上。用单点值做 ROI 测算一定会错。
2. **中位数优先**：判断「我进去大概能卖多少」用中位数，判断「这个市场有多大」用求和。两者回答的是不同问题。
3. **多源交叉**：卖家精灵、Helium 10、前台手动数评三者对不上的时候，以保守值做决策，不要取最有利的那个。

## 评分工制（本 demo 的落地规则）

评分把两层框架变成可计算的规则。每条阈值标注来源：**原文** = 框架原文写明的数字；**已确认** = 原文只给了方向、由 demo 补档，用户于 2026-11-18 确认沿用；**自定** = 由 demo 补档，尚未经用户确认。

**第一层（容量与需求）**

| 指标 | 分档 | 来源 |
|---|---|---|
| 核心词月搜索量 | ≥ 10,000 通过；< 10,000 否决 | 原文 |
| 核心词月增长率 | > 10% 通过；0—10% 需论证；< 0 不利 | 原文给 >10%，其余为分档 |
| TOP100 月均销量 | 600—3,000 通过；< 600 不利；> 3,000 需论证 | 原文 |
| 类目月总容量 | 参考项，不计分，结合客单价看 GMV | 原文 |
| 新品进榜数量与占比 | 数量 ≥ 5 且占比 ≥ 10% 通过；占比 < 10% 否决；数量 < 5 需论证 | 原文 |

**第二层（竞争格局）**

| 指标 | 分档 | 来源 |
|---|---|---|
| 前三品牌集中度 | > 40% 否决；30—40% 需论证；≤ 30% 通过 | 原文给 40%，30% 已确认 |
| Top10 销量集中度 | > 60% 不利；45—60% 需论证；< 45% 通过 | 原文给「近 6 成」，45% 已确认 |
| Top20 平均评论数 | ≤ 800 通过；800—10,000 需论证；≥ 10,000 不利 | 原文 |
| 点击集中度 | < 40% 通过；40—60% 需论证；> 60% 不利 | **已确认**，原文只给方向 |
| 市场平均评分 | ≤ 4.3 通过；4.3—4.7 需论证；> 4.7 不利 | 原文 |
| 中位数 / 均值 | ≥ 0.6 通过；0.35—0.6 需论证；< 0.35 不利 | **已确认**，原文只要求「先看中位数」 |

- **每项三档**：`pass`（1 分）/ `warn`（0.5 分）/ `fail`（0 分），参考项不计分。
- **否决项**：前三品牌集中度 > 40%、新品占比 < 10%、核心词月搜索量 < 10,000，任意一项命中即整体判负，不再看其他分数。
- **判定**：命中否决线或第一层 < 60% → 放弃；第二层 < 50% → 风险偏高；有不利项或需论证项 ≥ 3 → 有条件进入；其余 → 可以进入细评。
- 所有阈值集中在 `src/scorer.js` 顶部的 `THRESHOLDS` 对象里，改口径只改那一处。

> 补档保留缓冲带的理由：品牌集中度、销量集中度都是工具估算值（前者误差来自「同品牌多链接归属判定可能漏并」，后者来自 BSR 反推），在估算值上不宜设悬崖边界。所有补档已于 2026-11-18 经用户确认沿用。

## 常见误用

- **只看 TOP100 月均销量就下单**：那是结果指标，不是原因。要回头去看是哪些词、哪些场景在贡献销量。
- **把新品数量高当成机会唯一证据**：新品进榜可能来自测评或站外，进榜后守不住的不算。
- **忽视 CPC 与点击集中度的联动**：自然位被垄断时，广告是唯一入口，此时真实获客成本远高于标称 CPC。
- **用均值估算自己的销量**：头部拉动型市场里，均值离中位数越远，均值越没有参考价值。
